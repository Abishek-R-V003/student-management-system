# 🎓 Student Management System (SMS)

A professional, secure student record management system built with **Django 6.0**.

## 🚀 Key Features
- **Passwordless OTP Authentication:** Secure login using Student Register Number and 6-digit OTP sent via Gmail (SMTP).
- **Admin Dashboard:** Real-time statistics on total students, active students, and course enrollments.
- **Student Management:** Complete CRUD operations for student profiles including photo uploads and department assignment.
- **Academic Tracking:** Course management and grade entry with automatic GPA calculation.
- **Attendance System:** Daily attendance tracking per course with status monitoring (Present/Absent/Late).
- **CSV Reporting:** Export student academic reports to CSV for administration.

## 🛠️ Technology Stack
- **Backend:** Python 3.12, Django 6.0.6
- **Database:** SQLite3
- **Frontend:** Bootstrap 5, HTML5, CSS3, JavaScript
- **Email Service:** Google SMTP (Gmail App Passwords)
